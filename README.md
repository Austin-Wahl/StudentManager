# Student Manager

Student Manager is a JavaFX application built for UTSA CS-2123 which illustrates the usage of HashTables and Priority Queues through a custom implementation.

## Technologies

- Java
- JavaFX

## Data Structures

The following data structures were built from the ground and do not use external dependencies except Arrays and ArrayLists

- PriorityQueue
- HashTable

## Additional Info

This application supports basic CRUD operations. Users can:

- Create Users
- Update Users
- Delete Users
- Search Users
- Read Users

Content is stored locally on disk in a `data.txt` file. If this file does not exist, it automatically creates it. Data prepopulated within this file is not randomly generated and is packaged statically within the binary.

## Download

This program is bundled with JavaFX and the Java21 runtime and requires no external dependencies. You can download releases for the following architectures:

- Windows x86 (32-bit)
- Windws x64 (64-bit)
- Mac OS Apple Silicon
- Mac OS x86_64

## Building the project

Run the following command to build the repository from scratch:

> If you're running this on Windows, please make sure you installed chocolatey. Additionally, this must be ran within the bash envrionment. You can install a bash terminal from online.

> If you're running this on Mac OS, please make sure you have homebrew installed.

`chmod +x ./build.sh && ./build.sh`

The script will only build this application for all platforms supported by jpackage. If you're running on Mac, you can not build Windows and vice versa.

## Generating Random Seed Data

Seed/test data can be generated by compiling the `DataGen` class located in `/src/main/java/utis/DataGen.java`. Compile with `javac DataGen.java` and run with `java DataGen`. The data is written to the file. Be sure to move the generated data.txt file to the `/src/main/` directory.

# Project Structure

- `/src/main/resources/data.txt` - Test Data
- `/src/main/resources/Views` - FXML views created with SceneBuilder
- `/src/main/resources/Views` - FXML views created with SceneBuilder
- `/src/main/resources/assets/images` - SVG's for icons and error/loading windows
- `/src/main/resources/styles` - CSS to add some character to the app
- `/src/main/java/controllers` - View Controllers for the FXML views
- `/src/main/java/dataStructures` - Custom data structures for this project
- `/src/main/java/models` - Data structures making it easier to interface with the data file and database
- `/src/main/java/utils` - Data gen script which creates a data.txt file
- `/src/main/java/StudentManager.java` - Entry point to the JavaFX application
